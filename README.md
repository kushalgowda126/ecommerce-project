# E-Commerce Website

A responsive E-commerce web application developed using React.js, JavaScript, HTML and CSS.

## Live Demo
[Visit Live Website](https://melodic-kelpie-0557fa.netlify.app/)

## Technologies Used
- React.js
- JavaScript
- HTML5
- CSS3
- React Router
- Context API
- useReducer
- REST API

## Features
- Product listing and product details
- Product search
- Shopping cart management
- Wishlist functionality
- Product category filtering
- Add, edit and delete products
- Dark and Light theme
- Responsive user interface
- API integration

## Installation

Clone the repository:

```bash
git clone https://github.com/kushalgowda126/ecommerce-project.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
